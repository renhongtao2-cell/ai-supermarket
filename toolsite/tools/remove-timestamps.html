Remove Timestamps from Subtitles

Strip timestamps and cue numbers to get a clean, readable transcript.

Your file never leaves your device

This tool is plain JavaScript. There is no upload step and no server-side processing, so confidential captions, unreleased content and client material stay on your machine.

What this does

Subtitle files are awkward to read and impossible to paste into a document. This tool keeps only the spoken text, dropping timestamps, cue numbers and formatting so you get a transcript you can actually use.

How to use it

  1. Paste or drop your .srt or .vtt file.
  2. Choose whether to merge consecutive duplicate lines — captioners often repeat a line across two cues.
  3. Copy the plain-text transcript.

Good to know

  • Multi-line cues are joined into a single line so the transcript reads naturally.
  • Turning on Merge repeated lines removes the duplication that comes from two-part captions.
  • If you also want to strip sound cues like [Music], use Clean subtitles first.

When you should keep the timestamps

A plain transcript is easier to read, but the timing is often the part you need later. Before stripping it, check whether the text will be used for subtitling (timing required), interview analysis (timecodes let you jump back into the recording), accessibility documentation (reviewers routinely ask for a timecoded transcript) or quotation with citation (a timecode is the citation).

If any of those apply, keep the original .srt or .vtt as the master file and treat the plain text as a derived copy. Keeping both costs nothing, and re-deriving the transcript later is one click.

Worked example

Input — .srt with timing
1
00:00:01,000 --> 00:00:04,000
Hello there.

2
00:00:04,200 --> 00:00:07,000
Hello there.

3
00:00:07,400 --> 00:00:10,000
How are you?
Output — plain text
Hello there.
How are you?

Timestamps and cue numbers are gone, and the repeated line from cue 2 is merged because Merge repeated lines is on. Turn it off and you get all three lines.

FAQ

Does this keep any timing information?
No. The output is plain text only. If you need the timing, use Shift subtitles instead, which preserves cues.
Why does my transcript repeat sentences?
Many captioners split a long line across two cues, so the same words appear twice. Enable Merge repeated lines to collapse them.
Which input formats are supported?
SubRip (.srt), WebVTT (.vtt), and most .sbv-style files that use the HH:MM:SS,mmm --> HH:MM:SS,mmm arrow syntax.

Troubleshooting

  1. Every sentence appears twice in the transcriptTwo-part captions repeat the line across consecutive cues. Enable Merge repeated lines to collapse them.
  2. Sound cues such as [Music] are still in the textThis tool removes timing, not noise. Run the file through Clean subtitles with Remove sound cues first, then strip the timestamps.
  3. Paragraph breaks are missingEach cue becomes one line of text. Paste into a word processor and replace line breaks with spaces if you want flowing paragraphs.
  4. The output is emptyNo cue lines were found. Confirm the file contains --> between timestamps — a plain transcript saved with a .srt extension has nothing to parse.
