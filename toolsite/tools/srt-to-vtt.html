SRT to VTT Converter

Convert .srt subtitle files to WebVTT (.vtt) for HTML5 video, right in your browser.

Drop a subtitle file here, or

Your file never leaves your device

This tool is plain JavaScript. There is no upload step and no server-side processing, so confidential captions, unreleased content and client material stay on your machine.

What this does

WebVTT is the subtitle format HTML5 <track> elements expect, while most subtitles you download are SubRip (.srt). This converter rewrites the timestamps and adds the required WEBVTT header — without sending your file anywhere.

How to use it

  1. Paste your SRT content into the box, or drop the .srt file onto it.
  2. The conversion runs locally as you type — no request is made to any server.
  3. Copy the result or download it as a .vtt file.

Good to know

  • SRT uses 00:00:01,000 (comma); WebVTT uses 00:00:01.000 (period). This is the single most common cause of subtitles silently failing to load.
  • Cue numbers are optional in WebVTT but are kept here so you can diff the output against the input.
  • Styling tags such as <i> and <b> are valid in both formats and are preserved.

FAQ

Why won't my .srt file work in an HTML5 video player?
Because HTML5 <track> elements only accept WebVTT. A file with an .srt extension, or with comma decimal separators in its timestamps, will be ignored by the browser without an error message.
Does this upload my subtitle file anywhere?
No. All parsing and conversion happens in JavaScript on your device. You can disconnect from the network after the page loads and the converter still works.
Is there a file size limit?
No server-side limit, because nothing is uploaded. The practical limit is your browser's available memory — files of several megabytes convert instantly.
