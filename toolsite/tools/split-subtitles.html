Split Subtitle Files

Cut one SRT or VTT track into two files at any timestamp, right in your browser.

Drop a subtitle file here, or

Your file never leaves your device

This tool is plain JavaScript. There is no upload step and no server-side processing, so confidential captions, unreleased content and client material stay on your machine.

What this does

A single subtitle track that covers a two-hour film, a double-episode recording or a lecture is awkward to edit, review or hand to a translator. Splitting it means choosing a cut point and writing every cue before that point into one file and every cue after it into another — which is exactly what this page does, with nothing leaving your device.

How to use it

  1. Paste your subtitle file into the box, or drop the .srt / .vtt file onto it.
  2. Set the split point — seconds, m:ss or h:mm:ss all work.
  3. Choose Part 1 or Part 2 and download it. Switch the dropdown to get the other half.

Good to know

  • Both parts keep the input format: an SRT in gives two SRTs, a VTT in gives two VTTs.
  • A cue that straddles the split point is kept whole in Part 1, so the two parts never share a broken line.
  • Part 2 keeps the original time codes. Use shift subtitles if you need it to start at zero.
  • To split into more than two parts, split once, then split Part 2 again at the next point.
  • The two parts are independent files — you can merge them back later with the merge tool if the split point was wrong.

What a correct split has to preserve

The obvious approach — cutting the text at a line boundary — breaks the file, because a cue is not a line. A cue is a number, a timing pair and one or more text lines, and cutting in the middle of that group leaves a file with a timestamp but no text, or text with no timestamp. This tool splits between cues, never inside one.

Timestamps are not re-based. Part 2 keeps the original time codes, so if you split a film at 45 minutes, the second file still starts at 00:45:00. That is what you want when the two halves are played back to back against the same video, and it is why the two files remain interchangeable with the original.

If you need Part 2 to start at zero instead — because it will be attached to a separately exported video clip — run it through the shift subtitles tool afterwards and pull it back by the split point. Doing both in one step would silently corrupt the first half.

Cue numbers are reassigned from 1 in each part. SubRip numbers are cosmetic to most players, but continuous numbering makes a file diff cleanly and keeps editors from complaining.

The cut is made on a cue's start time. A cue that straddles the split point — started before it, ends after it — stays whole in Part 1 rather than being sliced in half, because a half cue is always worse than a slightly uneven split.

Worked example

Input — one file, split at 00:01:00
1
00:00:10,000 --> 00:00:13,000
First half of the film.

2
00:00:58,000 --> 00:01:02,000
Still the first half.

3
00:01:05,000 --> 00:01:08,000
Now the second half.
Output — Part 1
1
00:00:10,000 --> 00:00:13,000
First half of the film.

2
00:00:58,000 --> 00:01:02,000
Still the first half.

Cue 3 starts after the split point, so it moves to Part 2. Cue 2 straddles it — it started before — so it stays whole in Part 1.

FAQ

Does Part 2 start at zero?
No, and that is deliberate. Part 2 keeps the original time codes so both halves line up with the same video. If you are attaching Part 2 to a separately cut video clip, run it through the shift subtitles tool afterwards.
What happens to a cue that crosses the split point?
It stays in Part 1, intact. Splitting a cue would leave one half with text and no sensible timing, so the cut always lands between cues.
Can I split into three or more parts?
Not in one step. Split at the first point, download Part 2, then paste it back in and split it at the next point. Repeat for as many parts as you need.
Do both halves keep the same format?
Yes. The output follows the input, so an SRT produces two SRT files and a VTT produces two VTT files. Convert first with the SRT to VTT converter if you need the other one.
Is my file uploaded?
No. Parsing and splitting happen in JavaScript on your device. You can disconnect from the network after this page loads and the splitter keeps working.

Troubleshooting

  1. Both parts are emptyNo cues were recognised. Check that the file uses --> between timestamps. A file renamed from SBV will not parse.
  2. Everything ended up in Part 1The split point is later than the last cue. Try 45:00 instead of 45 — a bare number is read as seconds, so 45 means 45 seconds in, not 45 minutes.
  3. Everything ended up in Part 2The split point is 0 or earlier than the first cue. Check the field contains a time, not a stray character.
  4. The download is named part2 but shows Part 1 contentThe dropdown and the download name are set together, so re-select the part and download again. The name always matches what is in the output box.
  5. Part 2 plays at the wrong timeIt intentionally keeps original timings. Pull it back to zero with the shift subtitles tool if the video it belongs to was cut separately.
